# Magical Friends Coloring Book landing page

GitHub Pages package for Glenda E. Tress Books.

## Publish

1. Create a public GitHub repository named `magical-friends`.
2. Upload every file from this package to the root of the repository.
3. Commit the files to the `main` branch.
4. In **Settings → Pages**, choose **Deploy from a branch**, then select **main** and **/(root)**.
5. The page will appear at:
   `https://glendaetressbooks.github.io/magical-friends/`

The page includes the Amazon link, six preview images, the shared MailerLite
sampler form, and a link back to the Glenda E. Tress Books homepage.
